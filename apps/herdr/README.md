# herdr

Colour overrides for herdr's UI.

## Install

This one is applied by hand, see Activate below.

## Activate

herdr keeps theme colours in its main config, so this one is a paste. Replace the `[theme]` table in `~/.config/herdr/config.toml` with `theme.toml`, then run:

```bash
herdr server reload-config
```
