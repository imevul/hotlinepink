# superfile

Theme for superfile.

## Install

```bash
./install.py superfile
```

| File | Installed to |
|---|---|
| `hotline-pink.toml` | `~/.config/superfile/theme/hotline-pink.toml` |

## Activate

Set `theme = "hotline-pink"` in `~/.config/superfile/config.toml`.
