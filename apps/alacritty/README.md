# Alacritty

Colour theme for Alacritty.

## Install

```bash
./install.py alacritty
```

| File | Installed to |
|---|---|
| `hotline-pink.toml` | `~/.config/alacritty/themes/hotline-pink.toml` |

## Activate

Add this to `alacritty.toml`:

```toml
[general]
import = ["~/.config/alacritty/themes/hotline-pink.toml"]
```
