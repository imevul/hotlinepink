# Konsole

Colour scheme for Konsole.

## Install

```bash
./install.py konsole
```

| File | Installed to |
|---|---|
| `HotlinePink.colorscheme` | `~/.local/share/konsole/HotlinePink.colorscheme` |

## Activate

Settings > Edit Current Profile > Appearance, then pick Hotline Pink.

## Notes

Konsole colour schemes can't set a cursor colour, so the cursor follows the text colour unless you set a custom one in the profile.
