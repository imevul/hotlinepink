# fzf

Colour options for fzf, for fish and zsh.

## Install

```bash
./install.py fzf
```

| File | Installed to |
|---|---|
| `hotline-pink.fish` | `~/.config/fzf/hotline-pink.fish` |
| `hotline-pink.zsh` | `~/.config/fzf/hotline-pink.zsh` |

## Activate

Source `~/.config/fzf/hotline-pink.fish` from `config.fish`, or `~/.config/fzf/hotline-pink.zsh` from `.zshrc`.
