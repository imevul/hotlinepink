# Kate

Syntax highlighting theme for Kate and other KDE text editors.

## Install

```bash
./install.py kate
```

| File | Installed to |
|---|---|
| `hotline-pink.theme` | `~/.local/share/org.kde.syntax-highlighting/themes/hotline-pink.theme` |

## Switch it on

Your turn: the installer never edits your own configs.

1. Restart Kate.
2. Open Settings > Configure Kate > Color Themes and select Hotline Pink.

## Uninstall

```bash
./install.py --uninstall kate
```

1. In Kate, select another theme under Settings > Configure Kate > Color Themes.

Status: Loaded in the app.
