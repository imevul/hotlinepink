# opencode

TUI theme for opencode.

## Install

```bash
./install.py opencode
```

| File | Installed to |
|---|---|
| `hotline-pink.json` | `~/.config/opencode/themes/hotline-pink.json` |

## Activate

Add `"theme": "hotline-pink"` to `tui.json` or `tui.jsonc`, or pick it with `/theme`.
