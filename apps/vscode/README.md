# VS Code / Cursor

Colour theme extension for VS Code, Code - OSS and Cursor.

## Install

```bash
./install.py vscode
```

| File | Installed to |
|---|---|
| `hotline-pink/package.json` | `~/.vscode/extensions/imevul.hotline-pink-1.0.0/package.json` |
| `hotline-pink/package.json` | `~/.vscode-oss/extensions/imevul.hotline-pink-1.0.0/package.json` |
| `hotline-pink/package.json` | `~/.cursor/extensions/imevul.hotline-pink-1.0.0/package.json` |
| `hotline-pink/themes/hotline-pink-color-theme.json` | `~/.vscode/extensions/imevul.hotline-pink-1.0.0/themes/hotline-pink-color-theme.json` |
| `hotline-pink/themes/hotline-pink-color-theme.json` | `~/.vscode-oss/extensions/imevul.hotline-pink-1.0.0/themes/hotline-pink-color-theme.json` |
| `hotline-pink/themes/hotline-pink-color-theme.json` | `~/.cursor/extensions/imevul.hotline-pink-1.0.0/themes/hotline-pink-color-theme.json` |

## Switch it on

Your turn: the installer never edits your own configs.

1. Restart the editor.
2. Open the command palette, run Preferences: Color Theme, and select Hotline Pink.

## Uninstall

```bash
./install.py --uninstall vscode
```

1. Select another colour theme in the editor, then restart it.
