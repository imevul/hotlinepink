# eza

Theme for eza.

## Install

```bash
./install.py eza
```

| File | Installed to |
|---|---|
| `theme.yml` | `~/.config/eza/theme.yml` |

## Switch it on

Nothing more to do. eza reads this file automatically. An `LS_COLORS` or `EZA_COLORS` variable can still override it.

## Uninstall

```bash
./install.py --uninstall eza
```

Status: Loaded in the app.
