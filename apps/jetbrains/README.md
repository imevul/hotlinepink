# JetBrains IDEs

Editor colour scheme for JetBrains IDEs. It covers the editor only, not the IDE UI.

## Install

The installer doesn't copy anything for this app, so follow the steps below.

## Switch it on

Your turn: the installer never edits your own configs.

1. In the IDE, open Settings > Editor > Color Scheme.
2. Click the gear icon, choose Import Scheme, and select `HotlinePink.icls`.

## Uninstall

1. Select another scheme under Settings > Editor > Color Scheme.

Status: Syntax checked only.
