# bat

Syntax theme for bat. delta uses it too.

## Install

```bash
./install.py bat
```

| File | Installed to |
|---|---|
| `hotline-pink.tmTheme` | `~/.config/bat/themes/hotline-pink.tmTheme` |

## Activate

```bash
bat cache --build
```

Then add `--theme="hotline-pink"` to `~/.config/bat/config`.

Status: Loaded in the app.
